# PyWorkflowKit 1.1.0a1

## Developer Experience — DX01

PyWorkflowKit 1.1.0a1 starts the 1.1 Developer Experience & Learning line on top of the
qualified 1.0.0 runtime baseline.

This alpha introduces no new workflow-runtime semantics.

## Added

- canonical short CLI command: `pwk`;
- compatibility aliases remain available: `pyworkflowkit` and `pyworkflow`;
- executable qualification proving all three entry points resolve to the same CLI;
- parity checks for version output, validation JSON, planning JSON, and handled-error exit codes.

## CLI identity

```text
PyPI package       pyworkflowkit
Python namespace   pyworkflowkit
Canonical CLI      pwk
Long CLI alias     pyworkflowkit
Compatibility CLI  pyworkflow
```

Examples:

```bash
pwk version
pwk validate examples.getting_started_workflow:demo --json
pwk plan examples.getting_started_workflow:demo --json
```

## Compatibility

CLI Machine Contract v1 remains in force.

Adding `pwk` is additive. Existing command names, JSON keys, stream behavior, and
application-owned exit-code meanings are unchanged.

The frozen RQ-01 through RQ-06 contracts continue to represent the 1.0 compatibility
baseline. Qualification for 1.1 no longer assumes that the currently installed package
must remain version 1.0.0.

## Out of scope

This release does not yet add:

- Rich terminal rendering;
- the full Zero-to-Hero guide set;
- the expanded canonical examples;
- interactive notebooks.

Those are scheduled for the next 1.1 milestones.
