# PyWorkflowKit 0.3.0

Release date: 2026-09-26

## Capability

PyWorkflowKit 0.3.0 is a local developer framework with durable persistence,
decorators, CLI, configuration, observability, plugin foundations, and an optional
PyIngestKit integration boundary.

This release closes milestones M17 through M24 while incorporating the durable
persistence and evidence work completed in the 0.2 capability line.

## Highlights

- `RuntimeSettings` and `RuntimeFactory` composition.
- Small public `WorkflowRuntime` facade.
- Lazy `@task` / `@workflow` declarative API.
- Operational CLI: validate, plan, run, inspect, events, manifest, plugins, doctor,
  and version.
- Structured runtime diagnostics and redaction.
- Typed plugin foundation with plugin API version 1.
- Opt-in entry-point discovery and compatibility diagnostics.
- PyIngestKit anti-corruption adapter treating an ingestion job as one atomic task.
- Durable SQLite and PostgreSQL metadata persistence with Alembic migrations.
- Stable runtime evidence through events, manifests, artifacts, external references,
  and lineage.

## Qualification

The 0.3.0 release gate requires:

- Ruff lint and format checks;
- strict mypy over `src`;
- pytest with branch coverage >= 90%;
- Python 3.11, 3.12, and 3.13 matrices;
- wheel build and isolated installation smoke;
- reference acceptance workflows;
- PostgreSQL persistence and migration contracts;
- package/CLI version consistency.

## Architectural boundaries

0.3.0 does not introduce:

- scheduling;
- distributed workers;
- web UI or control plane;
- RBAC or multi-tenancy;
- concurrent DAG dispatch;
- process/async/subprocess execution;
- crash recovery/resume.

PyIngestKit remains optional. PyWorkflowKit core does not import PyIngestKit and treats
an ingestion job as an atomic workload represented through normal TaskResult and
ExternalRunRef evidence.
