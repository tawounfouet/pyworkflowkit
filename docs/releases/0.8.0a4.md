# PyWorkflowKit 0.8.0a4

Development milestone: M50 — Reference Integration Packages

## Capability

0.8.0a4 proves that PyWorkflowKit's interoperability contracts can be consumed by
independently packaged Python distributions using real entry points and isolated wheel
installation/removal.

## Added

Four reference integration distributions:

~~~text
pyworkflowkit-reference-workload
pyworkflowkit-reference-event-sink
pyworkflowkit-reference-metadata
pyworkflowkit-reference-pyingestkit
~~~

They exercise the existing workload, event and metadata entry-point groups without adding
new plugin categories.

## External workload

The reference workload package creates a generic M47 ExternalWorkload and produces
portable M48 ExternalRunRef evidence.

## Event sink

The reference event package implements RuntimeEventSink and proves an independently
installed sink observes the same committed event IDs as durable runtime evidence.

## Metadata plugin

The reference metadata package proves real wheel discovery, compatibility validation,
UnitOfWork creation and WorkflowRun persistence through the MetadataStore plugin
contract.

## PyIngestKit

The PyIngestKit reference adapter is outside the core wheel.

CI installs the real PyIngestKit repository pinned at:

~~~text
a19264845e10769fb8fd8cd42c83193ae011f702
~~~

which reports version 1.0.1.

A real PyIngestKit Job/Pipeline/Step executes through its Runner and is represented as one
atomic PyWorkflowKit external workload with provider `pyingestkit`.

## Isolation qualification

A new isolated-venv harness performs:

~~~text
build integration wheel
install
discover
explicitly enable
execute
uninstall
verify entry point absent
execute core-only workflow
~~~

for every package.

## Release qualification

The integration-package harness now runs both in regular CI and as a required Release
Qualification gate.

## Compatibility

- package-root API unchanged;
- Plugin API version unchanged;
- RuntimeEvent vocabulary unchanged;
- no new PluginType;
- no persistence migration;
- no PyIngestKit core dependency;
- no automatic plugin installation or enablement.
