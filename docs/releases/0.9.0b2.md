# PyWorkflowKit 0.9.0b2

Packaging and distribution stabilization beta.

## Objective

0.9.0b2 implements **RQ-05 — Packaging & Distribution**.

The release adds no runtime capability. It qualifies the wheel and source distribution
that downstream users will actually install.

## Added

- Distribution Contract v1 targeting `1.0.0`;
- explicit minimal sdist contents;
- artifact metadata/content qualifier;
- wheel rebuilt-from-sdist equivalence check;
- clean core installation gate;
- isolated published-extra installation gates;
- stable package upgrade gate from the exact `0.8.0` commit;
- built-artifact distribution gate in Release Qualification.

## Changed

- the development line advances from `0.9.0b1` to `0.9.0b2`;
- Hatchling is bounded to `>=1.27,<2`;
- development-tool extras use explicit compatibility ranges;
- project metadata now exposes Homepage, Documentation, Repository, Issues, Changelog,
  and Security URLs;
- README guide links are absolute so the package description remains navigable on a
  package index.

## Artifact contract

The official distribution must contain:

```text
one pure-Python wheel
one source distribution
```

The wheel contains only the package and dist-info metadata. The sdist contains only the
build metadata, distribution-facing root documents, and `src/pyworkflowkit/**`.

## Upgrade qualification

Release Qualification builds the stable `0.8.0` wheel from:

```text
70cf048ca7264c9c6caf79fd28801f0db50973c5
```

and proves an in-place package upgrade to `0.9.0b2` in a fresh virtual environment.

## License note

No software license is selected or inferred by RQ-05. That project/legal decision remains
explicitly separate from technical distribution qualification.
