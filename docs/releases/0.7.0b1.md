# PyWorkflowKit 0.7.0b1

Development milestone: M46 — Release Automation & Upgrade Matrix

## Capability

0.7.0b1 assembles the compatibility work from M41 through M45 into a dedicated release
qualification pipeline.

- release qualification contract v1;
- explicit supported Python matrix: 3.11, 3.12, 3.13;
- aggregated contract snapshot for CLI, manifest, plugin, persistence, and migration head;
- source-tree release metadata verifier;
- release-note presence and heading gate;
- CHANGELOG version gate;
- optional version-tag consistency gate;
- wheel and sdist build qualification;
- Twine metadata validation;
- SHA-256 artifact checksums;
- workflow artifact upload;
- wheel installation on Python 3.11/3.12/3.13;
- sdist installation on Python 3.13;
- installed-package contract validation outside the checkout tree;
- full reference-contract qualification;
- SQLite historical upgrade matrix on all supported Python versions;
- PostgreSQL historical upgrade matrix on all supported Python versions;
- release security gates;
- aggregate Release qualification gate.

## Artifact-first validation

The release workflow verifies the built distribution artifacts, not only editable
source installs.

Installed-package smoke tests execute from outside the repository checkout to ensure
imports resolve to the installed wheel or sdist.

## Tag rule

When the workflow runs for a tag:

~~~text
tag == "v" + project.version
~~~

A mismatch fails the release metadata gate.

## Publication

0.7.0b1 adds qualification automation only.

It does not automatically:

~~~text
publish to PyPI
create a GitHub Release
push a tag
~~~
