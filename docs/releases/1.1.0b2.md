## Learning model

The notebook surface deliberately follows:

```text
Concept
   ↓
Construction
   ↓
Inspection
   ↓
Modification
   ↓
Execution
   ↓
Observation
   ↓
Experiment
```

The notebooks are not copies of the canonical scripts split into cells.

## Dependency boundary

The canonical notebook files contain ordinary Python code and require no notebook magic.
CI parses and executes them using the Python standard library, so Jupyter does not become a
PyWorkflowKit runtime dependency.

Users may open the files with any Notebook v4-compatible environment such as JupyterLab,
Jupyter Notebook, VS Code, or PyCharm.
