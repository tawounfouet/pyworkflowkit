# PyWorkflowKit 1.1.0b1

## Developer Experience — DX04

PyWorkflowKit 1.1.0b1 adds the canonical executable Python example suite that complements
the Zero-to-Hero guides introduced in 1.1.0a3.

This beta introduces no workflow-runtime semantic change.

## Added

- canonical example index at `examples/README.md`;
- numbered executable scripts `00_hello_world.py` through `21_control_plane.py`;
- canonical examples for tasks, workflow definitions, dependencies, DAG shape, execution
  planning, runtime execution, RunContext data flow, failure, retry, events, manifest,
  SQLite, PostgreSQL configuration, runtime configuration, concurrency eligibility,
  timeout/cancellation capabilities, external workloads, plugins, custom executors, and
  the control-plane provider;
- atomic PyIngestKit integration example under
  `examples/integrations/pyingestkit/atomic_job.py`;
- complete durable `fetch → validate → transform → publish` reference application under
  `examples/complete/data_pipeline.py`;
- DX04 reference acceptance that executes every canonical example in a clean Python
  process and validates its JSON output.

## Public-boundary rule

Canonical examples avoid imports from frozen internal module families such as
`pyworkflowkit.application`, `pyworkflowkit.adapters`, `pyworkflowkit.domain`, and
`pyworkflowkit.ports`.

They use the public surfaces appropriate to each concept:

```text
pyworkflowkit
pyworkflowkit.ecosystem
pyworkflowkit.control_plane
```

The specialized PyIngestKit example uses its documented integration adapter boundary.

## Optional integrations

The PostgreSQL example validates configuration and redaction without requiring a live
database server. A real PostgreSQL runtime still requires:

```bash
python -m pip install "pyworkflowkit[postgres]"
```

The PyIngestKit example demonstrates the anti-corruption adapter contract without requiring
the concrete PyIngestKit package.

## Preserved

- stable 1.0 runtime contracts;
- CLI Machine Contract v1;
- the intentionally small package-root API;
- product boundaries between PyWorkflowKit, PyIngestKit, and external control planes.
