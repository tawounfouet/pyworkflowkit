# PyWorkflowKit 0.7.0a3

Development milestone: M43 — CLI & Machine Contract Freeze

## Capability

0.7.0a3 formalizes the existing CLI as machine contract v1.

It preserves the command behavior already shipped while converting implicit JSON and
exit-code expectations into explicit executable contracts.

## Frozen command surface

~~~text
validate
plan
run
inspect
events
manifest
plugins
doctor
version
~~~

## Application exit codes

~~~text
0 success
2 validation
3 run failure
4 doctor failure
~~~

## JSON contracts

M43 freezes required top-level and nested keys for validate, plan, run, inspect, events,
plugins, doctor, and manifest.

Handled --json errors retain:

~~~json
{"error":"...","exit_code":N}
~~~

on stderr.

## Manifest

manifest --json continues to use RunManifest schema version 1. M43 does not create a
parallel CLI-specific manifest representation.

## Version

version remains one line of plain text matching the installed package version.

## Compatibility rule

Required keys and meanings cannot disappear silently. Additive optional fields remain
compatible, but must be deliberate and covered by contract tests. Removal, rename, type
repurposing, stream changes, or exit-code semantic changes require deprecation or an
explicit machine-contract transition.

## Runtime impact

None.

No executor, persistence, recovery, state-machine, event-taxonomy, plugin, or migration
behavior changes in M43.
