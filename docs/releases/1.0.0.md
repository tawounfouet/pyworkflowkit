# PyWorkflowKit 1.0.0

First stable release of PyWorkflowKit.

## Status

```text
Stable Embeddable Workflow Runtime
```

PyWorkflowKit 1.0.0 is promoted from the fully qualified `0.9.0rc1` release candidate.

No runtime capability is added by this promotion.

## Promotion policy

The stable release follows the RQ-06 rule:

```text
same-qualified-code-version-metadata-only
```

The implementation under `src/pyworkflowkit/**` is unchanged from the qualified RC.

The stable promotion changes only release-facing metadata, qualification expectations,
and documentation needed to represent the same implementation as `1.0.0`.
