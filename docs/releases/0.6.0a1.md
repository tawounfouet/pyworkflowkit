# PyWorkflowKit 0.6.0a1

Development milestone: M37 — Recovery Foundation

## Capability

PyWorkflowKit 0.6.0a1 introduces read-only recovery diagnostics over durable runtime
evidence.

It can identify stale run candidates and classify whether persisted evidence is
structurally eligible for a future resume or first requires reconciliation.

It does not perform recovery state mutations.

## Added

- RecoveryInspector;
- RecoveryAssessment;
- RecoveryLiveness;
- ResumeEligibility;
- TaskIdempotencyMetadata;
- MetadataStore.list_workflow_runs();
- Memory workflow-run listing;
- SQLAlchemy workflow-run listing;
- WorkflowRuntime.recovery_assessment();
- WorkflowRuntime.stale_run_candidates();
- SQLite crash-state restart acceptance.

## Liveness

```text
TERMINAL
ACTIVE
STALE_CANDIDATE
UNKNOWN
```

Staleness uses a caller-configured threshold over the latest persisted timestamp.

A stale candidate is not proof that the workload is dead.

## Resume assessment

```text
NOT_ELIGIBLE
ELIGIBLE
REQUIRES_RECONCILIATION
```

M37 never invokes resume.

`REQUIRES_RECONCILIATION` is produced when a stale candidate still has:

- a RUNNING TaskRun;
- a RUNNING TaskAttempt;
- external work attached to a non-terminal task.

## Idempotency

For each TaskRun:

```text
idempotency_key = task_run_id
```

The key is stable across retries because attempts change while TaskRun identity does not.

This is metadata support, not an exactly-once guarantee.

## Persistence

No migration is introduced.

M37 reuses existing:

- run/task/attempt timestamps;
- RuntimeEvent timestamps;
- ExternalRunRef evidence.

The MetadataStore port gains a workflow-run listing read method.

## Compatibility

0.6.0a1 leaves unchanged:

- lifecycle status enums;
- RuntimeEvent taxonomy;
- RunManifest schema version 1;
- Plugin API version 1;
- metadata schema;
- executor contracts;
- retry semantics;
- timeout semantics;
- cancellation semantics.

## Recovery boundary

0.6.0a1 does not add:

- heartbeats;
- leases;
- worker ownership;
- automatic resume;
- external reconciliation;
- exactly-once claims.
