# PyWorkflowKit 1.0.0

First stable release of PyWorkflowKit.

## Status

```text
Stable Embeddable Workflow Runtime
```

PyWorkflowKit 1.0.0 is promoted from the fully qualified `0.9.0rc2` release candidate.

No runtime capability is added by this promotion.


## Why RC2 became the promotion baseline

The first stable-promotion attempt exposed an Ecosystem SDK v1 compatibility ceiling
ending at `<1.0`.

RC2 corrected the public compatibility metadata to:

```text
series            = 0.8-1.x
minimum           = 0.8.0b1
maximum_exclusive = 2.0
```

and aligned reference/template integration dependency ceilings to `<2.0`.

The complete RQ-06 corpus was rerun before stable promotion.

## Promotion policy

The stable release follows the RQ-06 rule:

```text
same-qualified-code-version-metadata-only
```

The implementation under `src/pyworkflowkit/**` is unchanged from the qualified RC2
commit.

The stable promotion changes only release-facing metadata, qualification expectations,
and documentation needed to represent the same implementation as `1.0.0`.
