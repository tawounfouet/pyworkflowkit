# PyWorkflowKit 0.5.0a3

Development milestone: M34 — SubprocessExecutor

## Capability

PyWorkflowKit 0.5.0a3 adds shell-free external-program execution with captured process
evidence and hard per-handle termination.

## Added

- SubprocessCommand immutable command specification;
- SubprocessResult captured result value;
- SubprocessExecutor;
- mandatory shell=False execution;
- explicit argv boundary;
- stdout and stderr capture;
- return-code capture;
- stdin, cwd, environment, and encoding inputs;
- SubprocessExecutionError for non-zero exits;
- subprocess_spawn and subprocess_command failure categories;
- bounded external-process concurrency;
- hard timeout and hard cancellation for directly owned child processes;
- M34 unit and reference acceptance coverage.

## Executor family after M34

```text
LocalExecutor
    synchronous / local

ThreadExecutor
    threaded / soft timeout / no cancellation

ProcessExecutor
    isolated Python process / hard timeout / hard cancellation

AsyncExecutor
    asyncio / soft timeout / cooperative cancellation

SubprocessExecutor
    external program / hard timeout / hard cancellation
```

## Security boundary

M34 intentionally does not expose shell=True.

The adapter passes argv directly to the operating-system process API. Broader controls
such as executable allowlists, environment restrictions, output quotas, process-tree
containment, sandboxing, and resource limits remain M36 Security Hardening scope.

## Compatibility

M34 leaves unchanged:

- package-root API;
- workflow/task/attempt lifecycle enums;
- RuntimeEvent taxonomy;
- RunManifest schema;
- MetadataStore schema and migrations;
- LocalExecutor behavior;
- ThreadExecutor behavior;
- ProcessExecutor behavior;
- AsyncExecutor behavior.
