# PyWorkflowKit 2.1.0

> **Status**: Stable  
> **Release Candidate**: `2.1.0rc1` (PR #120, commit `63e330b`)  
> **Date**: 2026-10-04  

PyWorkflowKit 2.1.0 is the **stable release** of the 2.1 enterprise series. It is the same code as the qualified `2.1.0rc1` with only version metadata promoted — zero functional delta, per the freeze policy `blocker-fixes-only-without-rc-reset`.

---

## What's New in 2.1

### 1. OpenTelemetry Distributed Tracing (LOT-35)
- Standard W3C TraceContext propagation across workflow, task runs, and external workloads.
- Strict isolation of optional OpenTelemetry dependencies (`pyworkflowkit[otel]`) with zero runtime overhead when absent.
- Full span hierarchy: `WorkflowRun` root span parenting `TaskRun` spans, attempt spans, and external workload execution.
- Deterministic trace context injection and extraction across async boundaries and process borders.

### 2. Supply Chain Security & PyPI OIDC Trusted Publishing (LOT-36)
- Passwordless publishing to PyPI via GitHub Actions OpenID Connect (OIDC).
- Cryptographic provenance and signatures generated with Sigstore / Cosign.
- Software Bill of Materials (SBOM) automatically generated in CycloneDX JSON format.
- Automated distribution qualification verifying zero repository leakage.

### 3. Modular CLI & Frozen Machine Contract (LOT-31)
- Comprehensive Typer/Rich CLI architecture replacing legacy monolith:
  - `pwk run` : run workflows with interactive Rich rendering or strict `--json` machine output.
  - `pwk plan` : compile and display deterministic execution plans with dependency trees.
  - `pwk inspect` : query historical runs, status, attempts, and checkpoints.
  - `pwk manifest` : extract portable JSON-native run manifests and audit lineage.
  - `pwk store` : store management (list, prune, purge) with retention policies.
  - `pwk migrate` : apply and rollback Alembic schema migrations.
  - `pwk plugin` : discover, validate, and activate runtime plugins.
  - `pwk schema` : dump the current metadata store schema for SQL audit.
  - `pwk version` : display the package version.
- Machine contract (`cli_contract.py`) frozen as public API: 9 commands, strict JSON output.

### 4. Customer 360 v2 Reference Pipeline (LOT-37)
- End-to-end reference pipeline with `resume_run`, transactional pruning, and checkpoint reuse.
- Comprehensive E2E test suite: nominal, incident simulation, selective resume, upstream output reuse.

## Upgrade Guide

PyWorkflowKit 2.1.0 is fully backward-compatible with 2.0.0. No migration steps are required.

```bash
pip install pyworkflowkit==2.1.0
```
