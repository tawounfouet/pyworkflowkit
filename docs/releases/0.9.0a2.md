# PyWorkflowKit 0.9.0a2

Compatibility and deprecation stabilization alpha.

## Objective

0.9.0a2 implements **RQ-02 — Compatibility & Deprecation**.

The milestone does not add runtime features. It makes the existing compatibility boundary
explicit and executable before the typing-focused RQ-03 milestone.

## Added

- compatibility classification contract v1 targeting `1.0.0`;
- explicit `stable`, `deprecated`, `internal`, and `remove-before-1.0` statuses;
- machine-readable console-script aliases;
- frozen RuntimeSettings precedence and defaults;
- explicit stable exception exports through frozen facades;
- explicit internal module-prefix classification;
- compatibility snapshot embedded in the release qualification snapshot;
- source and built-wheel RQ-02 acceptance gates.

## Compatibility correction

Ecosystem SDK contract v1 previously advertised:

```text
>=0.8.0b1,<0.9
```

which excluded PyWorkflowKit 0.9 despite no SDK contract-version change.

0.9.0a2 corrects the supported range to:

```text
>=0.8.0b1,<1.0
```

The ecosystem template, reference integrations, qualification fixtures, unit/reference
tests, and artifact conformance scripts use the same upper bound.

## Deprecation state

```text
ACTIVE_DEPRECATIONS          = ()
deprecated subjects          = ()
remove-before-1.0 subjects   = ()
```

No API is deprecated and no removal is scheduled by this release.
