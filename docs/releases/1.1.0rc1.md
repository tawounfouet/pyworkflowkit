## Release Qualification

A dedicated 1.1 Developer Experience job runs against the built wheel while using the
checked-out guides, examples, notebooks, and acceptance tests as repository evidence.

The final Release Qualification gate requires this DX06 job in addition to the inherited
1.0 compatibility, typing, packaging, ecosystem, migration, and security families.

## Promotion rule

If `1.1.0rc1` remains fully qualified, promotion to `1.1.0` must use the same
implementation and change only release/version metadata.
